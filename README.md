# Grow With Us schedule (embed)

Published copy of the Sunday schedule page, built for embedding in an iframe
on plantify.org. Source lives in the Plantify repo at
`02_Projects/2026-Grow-With-Us/03_Working/Sunday-Schedule/`; edit there and
re-run `build-embed.sh`, do not edit this copy.

The page posts its height to the parent window, so the embedding page can
resize the iframe and avoid an inner scrollbar.
